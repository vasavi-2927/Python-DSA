# Python DSA

A simple repository containing implementations of basic **Data Structures and Algorithms using Python**.

## Topics Covered

### Data Structures
- Arrays
- Linked List
- Stack
- Queue

### Searching Algorithms
- Linear Search
- Binary Search

### Sorting Algorithms
- Selection Sort

## Files

- `arrays.py` - Basic array operations
- `linkedlist.py` - Linked List implementation
- `stack.py` - Stack implementation
- `queue.py` - Queue implementation
- `linearsearch.py` - Linear Search algorithm
- `binarysearch.py` - Binary Search algorithm
- `selectionsort.py` - Selection Sort algorithm

## Running the Programs

Make sure Python is installed.

Run any file using:

```bash
python filename.py
